# Launch checklist

## Before sharing the link
- [ ] Buy domain (Cloudflare Registrar)
- [ ] hello@ / partners@ / intros@ / events@ via Cloudflare Email Routing
- [ ] Formspree ID set, every form tested
- [ ] Real email + Telegram replace placeholders
- [ ] Founder photo + LinkedIn
- [ ] Deploy to Cloudflare Pages / Netlify, connect domain
- [ ] Analytics + Search Console

## Business
- [ ] Company set up (Sdn Bhd or Singapore Pte Ltd)
- [ ] 5 written referral agreements signed (Singapore trip)
- [ ] Check employment contracts for non-compete / side income clauses
- [ ] 1 hour with a crypto lawyer (referral fees, "Advisory" name, SC Malaysia)
- [ ] Decide invoice/USDT payment process

## Track from day one
Intros made · intros to meetings · meetings to deals · deal value · fees collected · quotes seen (anonymised)

## 90-day goal
3 closed deals. If not, narrow focus or change the model.
